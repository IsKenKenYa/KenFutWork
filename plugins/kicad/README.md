# KiCad 电路

装好插件后，**Work 引擎**里出现「电路」一档。点「打开」唤起本机已安装的 KiCad，做原理图与 PCB。

## 前提

本机装好 KiCad（[kicad.org](https://www.kicad.org/download/)）。没装时 Work 引擎那一行会显示「本机未安装」，不会给一个点了没反应的按钮。

## 边界

KiCad 是你自己的桌面软件：我们不分发、不内嵌、不代理它的界面。唤起后就是一个独立进程，关掉工作台不影响它继续画图。

它是 Qt 原生应用，浏览器里跑不起来——把它塞进网页等于重写一个 KiCad，不是集成。所以这里如实做「唤起本机应用」。
