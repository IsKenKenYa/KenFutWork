# 米家插件（规划中）

状态：**方案待拍板，尚无实现代码**。规划文档见 [`docs/插件/米家插件规划.md`](../../docs/插件/米家插件规划.md)。

本目录是「米家设备」插件在仓库内的预留落点。目标能力（四条硬要求）：

1. 以插件形态交付：可安装、可卸载（走 `plugins/` bundle + 插件市场机制）。
2. 工作台侧栏出现入口，能查看并控制米家设备。
3. 安装后 agent 可直接控制设备（不要求先打开面板）。
4. 服务端重启后凭证仍然有效，不需要重新扫码。

规划文档里给了三条路线（A 现成 App（Home Assistant）+ 最小接入 / B 自研米家云客户端 + 内核补存储能力 / C 纯 MCP）与推荐路径；**拍板前请不要在此目录放实现**，避免出现装了不能用的半成品 bundle。

参考同目录下的既有示例：`plugins/example-clock/`（最小 bundle）、`plugins/demo-panel/`（全能力面演示）。
