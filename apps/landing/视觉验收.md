# 落地页视觉验收

final result: passed

这是按仓库中文文档命名规范保存的 design QA 报告。验收目标为 CatPaw 的单屏布局与鼠标点阵交互，按用户要求使用 KenFutWork 配色和 KF Logo；不是逐像素复制 CatPaw 品牌。

## 证据与尺寸

- 来源：`https://meituancatpaw.com/`。
- source visual truth path：`.scratch/landing-evidence/source-desktop.jpg`、`source-mobile.jpg`（均相对仓库根，第二项与第一项同目录）。
- implementation screenshot path：`.scratch/landing-evidence/desktop.jpg`、`mobile.jpg`、`hover-desktop.jpg`。
- 桌面 viewport / CSS / 截图像素：1280 × 720；手机：390 × 844；截图为 1 倍密度，无缩放归一化。
- 额外检查：320 × 568 无横向溢出，页面允许垂直滚动；下载弹窗可滚动且可关闭。
- 同一比较输入同时展示来源与实现的桌面全景、手机全景。大标题、右侧下载区及手机纵向阅读路径均保持原站结构；最终主图已改为 KF Logo。
- 聚焦证据：`hover-desktop.jpg` 展示鼠标附近的蓝紫点阵；`/private/tmp/kenfutwork-landing-evidence/download-desktop.jpg` 展示平台选择面板。标题、按钮、导航在全景中清晰可读，因此不另造重复裁切图。

## 五项视觉检查

| 项目 | 结论 |
| --- | --- |
| 字体与层级 | 使用仓库在用的 Momo Trust Display 字标及大标题，中文为系统字体；字重更偏 KenFutWork 品牌，是有意替换原站像素字体。标题两行、右侧产品定位与 CTA 层级清楚。 |
| 间距与布局 | 顶部导航、左大标题、右下载区、底部版权保持单屏结构；手机使用上下分区。1280 / 390 / 320 宽度均可使用。 |
| 色彩 | 正式品牌蓝 `#2e63fa`；背景调淡至桌面 0.6、手机 0.53；标题统一黑色，避免蓝字混入点阵。 |
| 图片与标识 | 顶栏使用正式 PNG；背景基于正式 Logo 的 KF 轮廓生成点阵，不含 CatPaw 商标；桌面上方小标识和主标识均可识别，手机主标识裁切保持轮廓可见。 |
| 文案 | KenFutWork 自身的 Code / Design / BYOK 定位；无虚构版本、用户量、评价或下载成功状态。未发布安装包如实显示。 |

## 交互与控制台

- 下载弹窗打开 / 关闭、Escape、点击遮罩关闭、macOS / Windows 选择均通过浏览器操作确认。
- 产品介绍的 Code / Design 切换更新对应内容。
- 手机导航展开、收起及从导航打开下载弹窗通过。
- 鼠标真实移动 / 经过后 `data-active=true`，径向遮罩位置随指针变化；截图确认附近点阵变紫，其余区域保持蓝色，文本和按钮不染色。
- 触屏不激活悬停、窗口失焦 / 指针离开恢复、卸载移除监听器由自动测试覆盖。
- 浏览器控制台检查无应用错误。开发预览仅有 Vite 连接和 React DevTools 提示；静态产物控制台无错误。
- 在 `http://127.0.0.1:4174/KenFutWork/` 实际加载静态产物，确认子路径下字体、Logo、背景及脚本可用。

## 比较与修复历史

1. [P2，已修复] 原容器 `overflow: hidden` 在缩放 / 焦点回归时滚动内部内容，裁切导航。改为 `overflow: clip`；重新加载真实预览后 header top 为 0，手机和桌面截图均完整。
2. [P1，已修复] 首版只做图片漂移，遗漏参考页的指针变色。核对原站 DOM 后补双层背景与指针径向遮罩，并增加移动 / 触屏 / 移出 / 清理回归测试。最终 hover 截图确认变色只发生在局部点阵。
3. [P2，已修复] 初稿抽象丝带未体现 Logo。按用户反馈生成 KF Logo 点阵，替换背景；随后将蓝色标题改为黑色、调淡背景并调整上方小 Logo 裁切，最终全景复查通过。

当前无未解决的 P0 / P1 / P2。P3：小字号版权和英文页脚可以在下一轮视觉调整中增大；当前不影响主要操作。
