# KenFutWork 落地页 demo

独立静态应用，只负责品牌展示和下载入口。参考 CatPaw 的单屏布局，使用 KenFutWork 蓝色、正式 Logo、Momo Trust Display 字标及原创点阵背景。与 `apps/web`、桌面壳和服务端没有运行时依赖。

## 本地预览

仓库根目录运行：

```bash
pnpm --filter @kenfutwork/landing dev
```

浏览器打开 `http://127.0.0.1:4173/`。

## 构建与检查

```bash
pnpm --filter @kenfutwork/landing build
pnpm --filter @kenfutwork/landing typecheck
pnpm --filter @kenfutwork/landing test
```

产物在 `apps/landing/dist/`。Vite 的 `base: "./"` 使入口、字体和背景均支持相对路径，可部署到域名根目录或 GitHub Pages 仓库子路径。

- Cloudflare Pages：构建命令 `pnpm --filter @kenfutwork/landing build`，输出目录 `apps/landing/dist`，构建根目录为仓库根目录。
- GitHub Pages：构建后上传 `apps/landing/dist` 为 Pages artifact；无需服务端或路由重写。本轮不创建部署工作流，也不发布。

## 交互和后续接线

下载弹窗用于查看平台选择的样式。尚无公开安装包，选择平台后显示真实的未发布状态；“查看发布”和“从源码开始”分别链接 GitHub Releases 与 README，不生成虚假的下载成功状态。

导航的使用指南、更新日志和 GitHub 已连接真实页面。产品介绍弹窗可切 Code / Design；这只是介绍面，不运行桌面工作台。将来安装包发布后，在 `src/DownloadPanel.tsx` 接入各平台直链即可。公共链接集中于 `src/links.ts`。

点阵主形状直接使用正式 KF Logo 的透明 PNG 与格点遮罩，上方装饰性小 Logo 已移除。鼠标进入主 Logo 区域时可轻微磁吸跟随，最大位移 24px；退出区域或窗口失焦后归位。探照灯照到空白区域会显露代码、终端、分支、画笔等方点阵装饰图案，照到 Logo 则局部变为蓝紫色。

左侧标题采用逐字 3D Letter Swap 风格，悬停后逐字翻到深蓝 / 紫色背面。背景的 Code / Design 等装饰文字排列在立体圆柱上，按滚轮或原生页面滚动转场；不阻止页面滚动和浏览器缩放。触屏不激活磁吸，减少动态效果偏好会停止翻面、Logo 位移和背景转动。

保留手机导航、原生模态框焦点约束、Escape 关闭和点击遮罩关闭。

## 素材

- `public/assets/logo-mark.png`、`public/favicon.png`：复用本仓正式品牌文件。
- `public/fonts/`：复用在用的 Momo Trust Display 和 OFL 许可。
- 正式 PNG 直接参与浏览器格点遮罩；上一版烘焙大小 Logo 的背景图已退役。动效来源与实现见 [素材生成说明](./素材生成说明.md)。
- 控件图标使用仓库已采用的 Lucide（ISC），由 `lucide-react` 提供。

本轮仅为本地 demo，不代表安装包或桌面产品已发布。
