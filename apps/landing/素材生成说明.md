# 品牌素材与交互动效

## 品牌素材

`public/assets/logo-mark.png` 与 `apps/web/public/logo-mark.png` 逐字节一致，权威源图为 `docs/视觉设计/logo/新版.png`。顶栏保留正式品牌，主点阵 Logo 直接由同一张透明 PNG 加 CSS 格点遮罩渲染，不重画轮廓。现行标识没有正式 SVG；不使用已退役的旧版 SVG，也不把位图嵌入 SVG 冒充矢量版。

上一版同时包含大小两枚 Logo 的 ImageGen 背景图已删除，因而可独立控制主 Logo 并移除上方的小 Logo。现行页面没有新增生成图片。

## 视觉参考与实现

- [ReactBits 3D Letter Swap](https://pro.reactbits.dev/docs/components/3d-letter-swap)：参考公开演示的悬停逐字翻面，独立实现于 `AnimatedTitle.tsx` / `animated-title.css`。
- [ReactBits 3D Text Reveal](https://pro.reactbits.dev/docs/components/3d-text-reveal)：参考公开演示的立体圆柱文字转场，独立实现于 `HeroBackground.tsx` / `hero-background.css`，由原生滚轮和页面滚动驱动。
- [CatPaw](https://meituancatpaw.com/) 与用户提供的截图：用于单屏布局、点阵和径向探照灯的行为参考，不复制其商标、图片或装饰图案。

没有复制 ReactBits Pro 付费源码或引入其依赖。当前实现使用已有 React、CSS 3D transform、原生指针 / 滚动事件及本仓 Lucide 图标库。装饰为 CodeXml、Terminal、GitBranch、Braces、PenTool、Layers；来源与许可沿用根 `THIRD-PARTY-NOTICES.md` 的 Lucide（ISC）条目。字体复用既有 Momo Trust Display，与 OFL 全文一起分发。

## 交互约束

- 磁吸最多 24px，不锁定系统光标，不拦截导航和按钮。
- 探照灯只显露径向范围内的装饰与颜色；退出窗口或失焦淡出。
- 触屏不激活悬停，减少动态效果偏好停用位移 / 翻转 / 圆柱转场。
- 滚轮监听为 passive，浏览器缩放组合键不会改变背景转角。
