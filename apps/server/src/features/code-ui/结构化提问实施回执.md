## 公共契约与生产消费

- `CodeUserInputService` 由 `user-input-types.ts` 定义；`user-input-broker.ts` 提供每内核实例的真实等待、回答结算、只读绑定查找、取消及关闭。
- `ask-user-question.ts` 经原工具注册表动态贡献 `AskUserQuestion`，使用可信实例、Task、Run、工具调用、主子会话及两种代际；不读取认证类型或访问令牌。问题只提供澄清答案，不改变工具权限。
- 原 ZCode Ask 严格问题、选项、预览、元数据与多题/部分/零回答协议由 `user-input-schema.ts` 适配；来源 SHA 与 Apache-2.0 修改说明在源码头部。
- 原 `code-ui/plugin.ts` 为每个内核构造同一个 broker，工具与宿主读取同实例。事件消费者、作用域撤销、Task 关闭与宿主释放沿既有插件生命周期接入。
- `CodeUiService` 将问题与结果写入原会话事件/快照；事务内验证所属运行和代际。原 `resolveInteraction` 在核所属主/子会话后分流问答及审批；不存在的 ID 拒绝，仅已知结算记录可幂等回执。
- 问题 payload 保留真实 raw toolCallId 与 run traceId；UI tool row/anchor 使用原 run/raw 复合身份，原 Dialog 和 renderer保持原链。
