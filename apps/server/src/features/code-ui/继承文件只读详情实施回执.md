# 继承文件只读详情实施回执

原 `conversationFileChangesV4` 已消费当前 Task 持有的完整历史详情。fork 或编辑保留前缀时，先从真实私有 journal 验证文件提交，再复制原 V4 完整结果及源 journal 大小/条数事实；不从截断 display 重建补丁，也不复制伪 Run、审批或文件恢复权限。

继承详情与 context/history 一同在原 Task/state/ACK 事务内发布。父 Task 删除后不再查询它的提交日志。普通源 Task 仍沿原 journal 读取；普通 snapshot 与 action 探测不读取完整补丁，因此降低详情预算不会破坏正常快照读取。

读取及继续复制都遵守当前实例治理的条数与字节预算，超限明确拒绝，不截断成成功响应。该模块只提供历史详情，不触碰当前文件。
