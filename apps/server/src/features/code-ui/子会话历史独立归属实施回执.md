# 子会话历史独立归属实施回执

本批承接原 forkAssistant 与子 SessionPane读取：复制完整可见后代转录、fresh session/turn/row/tool/父子关联及原目录；不复制原 TaskWork、native子恢复绑定或控制权限。

根成功轮次冻结完整可见根行与后代快照；背景子在A完成后继续输出，不回写A的历史事实。分叉按准确A截点读取冻结图。历史副本的运行中内容停止镜像，标题、summary及原 lastError明确说明“仅截至截点；源仍在原Task运行”，副本为 completedInterrupted，源不生成取消/完成事件。原schema没有精确cutoff枚举，该展示适配边界明确保留，不把源运行说成取消。

新根/state/child归属索引在同一发表事务内写入，并在附件发表之前可见；每个子索引核root/project/实际父/tool唯一关联，缺失、循环、多父及source索引复用可读拒绝。新独立转录可父删除后读取；再次fork同步重绑定冻结view与子图，不造伪AgentRun/TaskWork/child native。

只读owner/source事实随后续普通事件保留；只读child拒绝全部原命令，清 activeWorks、queue、pending/审批、后台work/control ID、row.actions、permissionGrant和planTransition。原readonlypane允许workspace rewind，因此后端拒绝与无canRewindFiles并行保留，不能只依赖前端readOnly。

子真实Write详情从source当前journal按冻结行校验后复制完整V4只读结果；按当前预算读取、不借父事件、不造恢复边界。原 listSessionSubagents用当前分支直接子、原20/1..100请求schema与结束时间/childId二元keyset分页；invalid cursor回首页，不能以空目录掩盖后端缺口。
