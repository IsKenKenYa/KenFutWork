## 行为与责任

ToolDefinition/PermissionInvocation声明有限 `planControl="enter"`，独立于read/write/execute。仅可信主Code Task且不混合资源access可进入；无scope、shared工具与worker/explore/review均拒绝。目录与kernel共用允许判定，原broker/claim绑定实际参数与effect，claim一次，不能把控制标记当文件或命令旁路。

code-ui插件向原动态工具缝注册strict空对象、code/core的EnterPlanMode。Provider沿同一Task锁与幂等事件只设置根snapshot.planEnabled/seq/revision；原mode/模型/canonical输入、主与附加目录、两代际和Run保持，不造guide用户行或第二loop。原观察者发布实际工具事实，不另发成功事件。guide与规划控制复用同一活动主Run/Task绑定predicate，额外规划检查根身份及primaryTurn。

真实调用signal可由SDK合成；仍核同一次可信Invocation及Task/Run/调用身份，并检查工具和父Run取消状态，不以signal对象必须相等误拒合法调用。权限、停止、撤权、Task非ready/删除/归档、目录和代际在Task锁内与发布前后重验，失败不报告假成功。
