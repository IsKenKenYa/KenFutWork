# 原前台子代理独立停止

日期：2026-10-06。分支：`codex/完整移植ZCode-Code界面`。

## 问题与接线

真实前台 `Task(run_in_background=false)` 已持有独立 TaskWork 与子运行 controller，但原 V4 快照跳过所有非 detached work。原 `ConversationStatusPanel` 以唯一 `childSessionId` 联接目录与 `workId`，缺少控制项使独立停止按钮无法出现。

根 Task 的 `backgroundWorks` 现在同时投影真实运行中的前台子控制项。沿用原 `cancelBackgroundWork({workId})`，不新增 RPC、UI 或执行身份。非运行态立即移除；前台仍已消费，不产生 `resultPending`、后台通知或自动续跑。

控制归根 Task，直接子目录仍归实际父会话。真实 running work 先于子目录发表；原组件已在该短窗口按唯一 child 身份补齐控制。嵌套子 pane 保持只读，由根会话准确停止对应孙 work。名称不参与关联，原组件同一 child 不双计；原按钮仍使用“后台任务”的统一措辞，本批未修改来源字节。
