# 完整输出历史独立归属

日期：2026-10-06。共享分支：`codex/完整移植ZCode-Code界面`。

## 问题与实现

成功轮的 Task/TaskOutput 与前台 Bash 工具结果仍持有父 Task 的私有捕获路径。原生 checkpoint 也携带这些引用，单改 UI 行不能保证分叉后的模型读取当前 owner。

当前实现以 `inheritedOutputs` 保存当前 Task 自己的只读 Blob、校验和与完整保留/丢弃统计。副本获得新 UUID 与 `code-output:` 引用，metadata 随原新根/state/ACK 事务发表；没有新建 Task Work、Run 或执行控制身份。准备失败只清本次目标；未知 COMMIT 沿原命令机制保留准备资源。

源事实来自真实已完成 Task Work，或前台 Bash 的已保存 exited canonical 捕获事实与固定 Task 私有目录。再次分叉从当前 owner 的 Blob 复制，source 只溯源。Task 删除在实际执行关闭后清理自己的 Blob 与两个固定宿主日志目录，不按任意记录路径删除，也不移动外部代码目录。

原 V4 根/子/完成视图、原生 messages/Delta/pending writes、已知 canonical artifact 使用同一精确字段语义重绑定。工具配对 ID、普通正文及其它通道保持；摘要保留原文，追加可核实的只读绑定表，后代合并别名。持久事实的 Code PromptSection 为后续新压缩重新提供当前 ID，沿既有插件扩展点注册，不改 app/worker 装配。

TaskOutput 可发现和分页读取只读输出；TaskInput/TaskStop/cancelBackgroundWork 仍只查真实工作。模型预览与原 UI 页分开：原 TaskOutput UI 行采用受预算约束的 canonical 页，避免把模型 128 字符预览当作完整页。
