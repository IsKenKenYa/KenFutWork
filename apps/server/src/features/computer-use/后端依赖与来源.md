# 桌面后端依赖与来源

第一方executor/桥接代码由KenFutWork实现，未复制外部参考项目代码。平台原语通过各平台公开API/CLI调用；源码事实与实测矩阵见`docs/调研/桌面ComputerUse后端调研.md`。

| 后端 | 运行依赖 | 上游许可/来源 | 当前验收 |
| --- | --- | --- | --- |
| macOS | 系统osascript/JXA、AppKit/CoreGraphics、screencapture；已锁定的@computer-use/nut-js用于键盘原语 | Apple SDK系统API；nut.js Apache-2.0，现有包许可证随依赖保留 | 源码和 CJS/helper 资源形态共 4 条真实回归通过，含 Unicode/恢复、强制取消及双窗口；完整 Task、原 UI 与签名安装包仍待验收 |
| Linux X11 | 同桌面会话DISPLAY、窗口管理器、xdotool、xprop、xrandr、ImageMagick import；可选python3-pyatspi/AT-SPI会话总线 | xdotool BSD-3-Clause，AT-SPI LGPL-2.1+；其余由发行版包保留版权/许可证 | provider已接现有service/平台dispatch，未在Linux实际桌面验收 |
| Linux Wayland | ScreenCast/RemoteDesktop portal、PipeWire、用户选择及会话授权 | XDG/GNOME官方API；PipeWire MIT及例外 | portal/PipeWire helper及执行器已静态接线，仅支持已授权像素源；应用发现/AT-SPI组合与真实Wayland验收仍缺，不以XWayland/X11替代 |
| Windows | 规划UIAutomation/User32及系统截图、输入helper | Microsoft公开API/.NET系统库 | UIA/User32/GDI provider已静态接线，未获得可用Windows交互环境，尚未实机验收 |

X11的输入坐标是X server根窗口坐标，截图与输入使用同一坐标空间；返回scaleFactor=1表达此映射，不声称LCD物理像素/桌面UI缩放相同。真实测试仍需覆盖负原点、旋转与RandR变换。窗口绑定使用真实XID及可用_NET_WM_PID；无进程属性时不伪造PID，无障碍接口明确不可用。缺失AT-SPI或应用不暴露树时给明确原因，允许截图/其他后端，不返回假AX树。

原生依赖必须在对应OS/架构发行产物及真实登录桌面验证。新后台实现不能只添加代码：必须通过同一ComputerUseExecutor、service、工具注册/权限/结果事件消费，并记录取消、断连及恢复边界。
