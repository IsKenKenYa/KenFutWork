# 上下文分析组件

内部包 `@kenfutwork/context-insights-ui` 保留 dsh-context 0.84.1 的原分类浏览器、趋势图、请求详情、组成图、估算与历史重建函数。组件通过属性接收数据，不加载 DSH 服务端或会话运行时。

KenFutWork 的宿主入口位于 `apps/web/src/components/workbench/zcode/host/ContextInspectionProvider.tsx`。会话工具条传入真实 Task ID，通过已初始化的工作台连接调用 `context-insights.list/read`。面板按需读取选中请求及前一条同 Run、同 Agent 请求；“读取历史上下文”读取列表中该 Agent 的其余请求，“更早请求”继续分页。关闭面板或切换请求后不再发布迟到响应。

模型输入来自最终调用的冻结快照。宿主只为原组件生成局部显示序号，保留消息前缀、重复消息和移除记录；不会将显示序号当作执行事件。曲线只包含已读取的请求，分类 token 使用原估算函数；供应商输入、输出和缓存用量单独显示，未提供的数值保持未知。正文默认原文或 JSON，Markdown 由用户切换。

原 JsonTree 菜单使用 body portal，面板使用同库 Modal，宿主负责背景不可交互状态；原组件负责键盘与焦点返回。主题变量随面板存在映射到当前主题，使菜单继承相同颜色。图标使用原 ICON_SYMBOLS，并在面板关闭时移除。分析面板不切换工作台模式或内容标签。

构建使用 `pnpm --filter @kenfutwork/context-insights-ui build`。来源核对使用 `node scripts/verify-context-vendor.mjs`；只有清单中哈希匹配的上游文件跳过 Biome 格式检查。新增或修改上游源码必须同步说明与来源记录。原 Apache-2.0、DeepSeek MIT 和 NOTICE 随独立客户端静态产物分发。

服务端记录入口及尚未覆盖的独立模型调用范围见 `docs/日志.md` 的“上下文检查的真实请求记录”。
