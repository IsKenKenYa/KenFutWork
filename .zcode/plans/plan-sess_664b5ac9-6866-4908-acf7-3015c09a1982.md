# macOS DMG 打包（aarch64 自包含，对齐 Windows 管线）

## 已拍板
完整自包含 .app+DMG（服务端 Node SEA 二进制 + 内嵌 PG + web + 随包运行时）；仅 aarch64；随包运行时全套对齐；沿用 `com.kenfutwork.desktop`/`KenFutWork`/`0.1.0`（打包版首启无缝复用现有测试数据）；ad-hoc 临时签名；产物不入库。

## 实施步骤

### 1. 依赖与运行时资产
- `apps/server` optionalDependencies 补 `@img/sharp-darwin-arm64`（与现有 sharp-win32-x64 对齐）
- `scripts/fetch-runtimes.mjs` SPECS 增加 darwin-arm64 资产（node v22 tar.gz / python-build-standalone aarch64-apple-darwin / uv aarch64 / Adoptium jre mac-aarch64；git 不带——宿主 git 优先逻辑已存在），下载后记录 sha256；跑 `pnpm fetch:runtimes` 落 `runtime/`

### 2. 平台感知修复（server）
- `desktop/runtimes.ts` RUNTIME_LAYOUT 探测写死 `.exe`（node.exe/python.exe/uvx.exe/java.exe/git.exe）→ 改平台感知（darwin 无后缀），附单测（复用同文件 binaryName 思路）

### 3. 打包脚本 `scripts/package-mac.mjs`（新）+ 根 script `package:mac`
镜像 package-win.mjs 六步，产出 `release/`：
- esbuild server（同一套 externals：node-pty 等）→ Node SEA → postject 注入 → **`codesign --force --sign -` 重签**（postject 注入会弄坏 arm64 强制签名，Windows 无此步）
- web 构建（`NEXT_PUBLIC_SERVER_BASE_URL=""` 同源）+ `_splash.html`
- PG：`@embedded-postgres/darwin-arm64/native/{bin,lib,share}` + pgmq shim + **复刻 pg-symlinks.json 符号链接**（libicudata.68.dylib 缺失前车之鉴，日志.md:29）
- supabase/、node_modules 子集（sharp-darwin-arm64 + node-pty darwin prebuilds，运行时经 `<exeDir>/node_modules` 解析）、runtime/ 整拷、中文说明.txt
- 独立成脚本（不重构同事的 package-win.mjs，避免并行会话冲突），文头注明统一 TODO

### 4. Tauri 配置（分平台，不动 Windows 侧）
- 新增 `src-tauri/tauri.macos.conf.json`（Tauri v2 自动按平台合并）：targets `["app","dmg"]`、icon 补 `icons/icon.icns`（文件已在，633KB）、darwin 资源映射（`release/KenFutWork-server` 无后缀名，Rust 侧 lib.rs:78-100 已有 cfg(not(windows)) 分支）、`minimumSystemVersion`
- 主 tauri.conf.json 保持 nsis 不动

### 5. 修「写进 .app 包内」隐患（打包态签名破坏点）
- `lib.rs desktop_env`（仅打包态生效）：`#[cfg(target_os = "macos")]` 注入 `KENFUTWORK_CHECKPOINT_ROOT=<data_dir>/checkpoints` 与 `KENFUTWORK_SANDBOX_ROOT=<data_dir>/sandbox`——缺省 `<exeDir>/data/checkpoints`、`<exeDir>/tmp/sandbox` 在 mac 打包态 = 写进 Contents/Resources（只读/毁签名）。Windows 行为不动（NSIS 装可写目录，现状可用）
- 附 cargo 单测覆盖 env 注入

### 6. 收集与忽略
- `collect-bundle.mjs` mac 分支：扫 `bundle/dmg/*.dmg` 收到仓库根
- `.gitignore` 补 `/KenFutWork_*.dmg`

### 7. 构建 + 真机验收
- 流程：`pnpm install`（新 optional dep）→ `pnpm fetch:runtimes` → `pnpm package:mac` → `pnpm --filter @kenfutwork/desktop build`（tauri build 会做 release 编译，首次较久；bundler 默认 ad-hoc 签名）
- 验收：`codesign --verify --deep` 通过；打开 .app → splash → 窗口 → 探活 3001 → 登录页出现 → 用现有 kenfutwork 账号登录（证明数据复用）→ Code 模式「打开文件夹」系统对话框 → 画布 iframe 正常
- 门禁：`pnpm test`（新增 runtimes/symlink 单测在内）+ `pnpm typecheck` + `pnpm lint` + cargo test（desktop 16 例）

### 8. 文档（同提交）
- apps/desktop/README.md 补「macOS 打包」节（步骤 + ad-hoc 签名的 Gatekeeper 说明：拷给别的 mac 需右键打开或 `xattr -cr`）
- docs/日志.md 回执登记

## 已知风险
- node-pty darwin prebuilds 是否齐（缺则源码构建，需 Xcode CLT，本机有）
- python/uv/jre 的 darwin 资产 URL 可用性（404 则该运行时跳过并记录，不阻断主包）
- 首次 release 编译 + 资产下载耗时较长

## 不做
- universal 双架构、公证与 Developer ID 签名、重构统一 package-win/package-mac（记 TODO）、Windows 侧行为任何变更
