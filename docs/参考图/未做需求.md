- **要什么**：转录里一行**可折叠**的「已工作 N 分 N 秒 >」；一轮结束后跟「最终总结」正文。

  可展开的已完成项。

- **依赖**：需要先定「目标/待办的持久化形状」（会话级？run 级？）——**这是设计决策，先拍板再动手**。

- **现状**：**能力有、UI 没有**。服务端有子代理缝（`apps/server/src/agent/sub-agents.ts` 的

  但**没有把「子代理」作为一等事件**暴露给前端，前端也没有列表 UI。
- **依赖**：需扩展 WS 事件（子代理 started/finished + 父子关系），或从现有 tool 事件推导。

### R4-1 模型旁「上下文容量 + 缓存命中」浮层 ｜ 未做
- **来源**：`模型旁边显示上下文容量和缓存命中等数据.png`
- **要什么**：模型选择器旁一个**圆形图标**触发浮层，内容：
  - `上下文容量 61.4万/100万 (61.4%)` + 进度条；

- **依赖**：先定「分类口径」（哪些算系统提示词、技能、MCP 工具…）与「缓存命中怎么取」
