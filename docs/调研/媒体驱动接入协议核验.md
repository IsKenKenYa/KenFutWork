# 媒体驱动接入协议核验

核验日期：2026-10-15。范围仅限用户指定的 [GRSAI Apifox](https://qmy27nhsd9.apifox.cn/452392911e0)、[newapi-docs-c2l](https://newapi-docs-c2l.pages.dev/)、[APIMart](https://docs.apimart.ai/cn) 及其站内页面。只对公开文档执行 GET；没有读取凭据、调用生成 API 或验证真实扣费。本文是协议研究，不是运行验收。

## 结论

“USB + 驱动”的落点可以继续使用现有 `ImageProvider` / `VideoProvider` 的提交、轮询与取消接缝，再交给既有 Job 恢复、保存和发布链。厂商差异集中在请求字段、任务标识、状态与结果提取。以下是映射建议，不是新增一套 Job 生命周期的理由。

| 文档对应服务 | 已确认的媒体协议 | 可复用标准接入的边界 | 需要驱动处理的差异 |
| --- | --- | --- | --- |
| GRSAI | 原生统一异步协议：`POST /v1/api/generate` + `GET /v1/api/result?id=…` | 另有同步 OpenAI Images 格式，可单独验证标准图片通道 | 原生 `replyType: "async"`、`id`、`results[].url` 与自有状态；不是当前文档中的 `callback: "-1"` 协议。[原生图片](https://qmy27nhsd9.apifox.cn/452392911e0.md)、[查询](https://qmy27nhsd9.apifox.cn/452409577e0.md)、[OpenAI Images](https://qmy27nhsd9.apifox.cn/512802278e0.md) |
| 用户给的 newapi-docs 站 | 该站当前是“小北API 使用文档”；视频自称 Sora 异步任务格式，图片为同步 OpenAI Images | 图片具备标准 Images 请求/响应形状；视频需已有 Sora 格式驱动才能靠配置接入 | 不能由此推论所有 New API 部署均支持同一视频协议或模型；该站视频只有创建、查询、内容下载文档。[主页](https://newapi-docs-c2l.pages.dev/)、[视频](https://newapi-docs-c2l.pages.dev/docs/video/)、[图片](https://newapi-docs-c2l.pages.dev/docs/paint/GPTImage.html) |
| APIMart | 图片、视频统一异步任务；提交返回 `task_id`，统一 `GET /v1/tasks/{task_id}` | 路径使用 `/v1/images/generations` 不等于同步 OpenAI Images 响应兼容 | 提交响应 `data[]` 内是任务引用，结果要再次查询；图片结果 URL 还可能是数组。[图片](https://docs.apimart.ai/cn/api-reference/images/gemini-2.5-flash/generation.md)、[视频](https://docs.apimart.ai/cn/api-reference/videos/veo3/generation.md)、[查询](https://docs.apimart.ai/cn/api-reference/tasks/status.md) |

三站所核验的媒体文档均没有给出可实现的远端取消端点或 `Retry-After` 契约。应标记“未确认”，不能凭 `cancelled` 状态名或类似 OpenAI 的 URL 猜测取消能力。[GRSAI 目录](https://qmy27nhsd9.apifox.cn/llms.txt)、[小北视频接口一览](https://newapi-docs-c2l.pages.dev/docs/video/)、[APIMart 任务目录](https://docs.apimart.ai/_llms/zh-hans/api.txt)

## GRSAI：优先可实现的原生驱动

### 提交、查询与返回

基础节点为 `https://grsaiapi.com`（全球）和 `https://grsai.dakka.com.cn`（国内）；示例使用 `Authorization: Bearer …`。图片及两类视频共用 `POST /v1/api/generate`，统一查询为 `GET /v1/api/result?id={id}`。[nano-banana](https://qmy27nhsd9.apifox.cn/452392911e0.md)、[GPT Image](https://qmy27nhsd9.apifox.cn/452409160e0.md)、[H3](https://qmy27nhsd9.apifox.cn/514679297e0.md)、[Agnes](https://qmy27nhsd9.apifox.cn/523334530e0.md)、[查询](https://qmy27nhsd9.apifox.cn/452409577e0.md)

当前用户给定页明确列出 `replyType = json | stream | async`，异步模式使用 `"async"`；当前请求 schema 没有 `callback` 字段。不能以旧版 `callback: "-1"` 作为本次实现依据。[当前 nano-banana 请求 schema](https://qmy27nhsd9.apifox.cn/452392911e0.md)

```json
{
  "model": "nano-banana-2",
  "prompt": "一只橘猫坐在窗边",
  "images": [],
  "aspectRatio": "1:1",
  "imageSize": "1K",
  "replyType": "async"
}
```

异步提交示例返回 `{"id":"…","status":"running"}`。查询和同步成功共用以下形状：`id`、`status` 必填，`progress` 为 0–100，`results[].url` 为图片或视频地址，`error` 为字符串。状态为 `running / violation / succeeded / failed`。HTTP 400 文档返回 `{id,status,error}`，其中 `status` 为 `violation` 或 `failed`。[提交响应](https://qmy27nhsd9.apifox.cn/452392911e0.md)、[查询响应及错误](https://qmy27nhsd9.apifox.cn/452409577e0.md)

```json
{
  "id": "供应商任务ID",
  "status": "succeeded",
  "progress": 100,
  "results": [{ "url": "https://供应商结果地址/result.png" }]
}
```

映射建议：`startAsync` 保存完整供应商 `id`；`pollAsync` 将 `running` 映射为等待，`succeeded` 映射为成功并提取全部结果，`failed / violation` 映射为失败并保留可读错误原因。供应商任务 ID 的前缀不可解析成模型、线路或本地任务身份；只按不透明字符串持久化。取消、轮询推荐间隔、幂等键、重复提交语义、任务保留时长、结果 URL 失效时间及 `Retry-After` 均未在上述文档确认。

### OpenAI / Gemini 标准路径

GRSAI 另有 `POST /v1/images/generations`，JSON 请求含 `model,prompt,image[],size,quality,background`，成功响应为 `{created,data:[{url}],usage}`；错误为 `{error:{message}}`。`POST /v1/images/edits` 则声明 multipart，但 `image` 在该文档中是字符串 URL，不能未经验证假设与标准二进制文件上传完全一致。两页都未声明异步 `task_id`。[generations](https://qmy27nhsd9.apifox.cn/512802278e0.md)、[edits](https://qmy27nhsd9.apifox.cn/512807352e0.md)

## 用户给的 newapi-docs 站：按小北部署边界处理

该站主页自称“小北API”，公开基础地址为 `https://api.xbyjs.top`；OpenAI 兼容客户端配置通常加 `/v1`。它是本次用户指定的一手部署文档，不能替代 New API 上游版本及其他部署的能力证明。[主页](https://newapi-docs-c2l.pages.dev/)、[快速开始](https://newapi-docs-c2l.pages.dev/docs/register/)

图片 `gpt-image-2` 使用 `POST /v1/images/generations`（JSON）或 `POST /v1/images/edits`（multipart 图片二进制，可含 mask）。只支持 `n:1`，结果为 `{created,data:[{url,revised_prompt}]}` 或 `b64_json`；`stream`、透明背景、Chat Completions/Responses 出图明确不支持。图片文档没有可供恢复的异步任务 ID/查询/取消接口，并提醒长连接可能在生成结束前断开。[图片完整文档](https://newapi-docs-c2l.pages.dev/docs/paint/GPTImage.html)

视频接口如下，均使用 Bearer 鉴权；不应把 `GET …/content` 误当作取消或重新提交。[视频接口一览](https://newapi-docs-c2l.pages.dev/docs/video/)

| 操作 | 路径 | 已证实内容 |
| --- | --- | --- |
| 创建 | `POST /v1/videos` | JSON 示例使用 `model,prompt,duration,aspect_ratio,resolution` 及参考素材数组；回 `{id,object:"video",status:"queued"}` |
| 查询 | `GET /v1/videos/{task_id}` | 使用创建返回的 `id`；参考图识别数量位于 `properties.input.reference_image_count` |
| 下载 | `GET /v1/videos/{task_id}/content` | 完成后下载视频，示例携带 Bearer |
| 取消 | 未确认 | 接口一览未给出取消操作 |

视频优先用 `reference_images`，多图顺序保留；另有 `reference_videos` 和 `reference_audio_urls`。素材必须是公网 HTTP(S) URL，不接受本地路径、内网、base64/Data URI；音频不能单独作为唯一素材。模型 ID 必须是本站模型广场公开名，时长、固定分辨率与价格由该部署模型表决定。[参考素材与模型规则](https://newapi-docs-c2l.pages.dev/docs/video/)

文档列出 `invalid_request / asset_processing_failed / content_policy_violation / video_generation_failed / service_unavailable / request_timeout` 错误码及人话说明，但没有给出完整 HTTP 错误包装、查询终态响应 schema、`Retry-After` 或幂等协议。驱动可实现创建与查询接线；终态/结果提取必须在取得完整协议或非付费样本后锁定，不能由“Sora 格式”三个字补写所有字段。[错误说明](https://newapi-docs-c2l.pages.dev/docs/video/)

Banana 图片页仅提供 Cherry Studio 配置教程（Gemini 分组、关闭流式等），没有正式请求/响应 schema；不能据截图教程承诺所有 Gemini 生图参数零代码兼容。[Banana 教程](https://newapi-docs-c2l.pages.dev/docs/paint/Banana.html)

## APIMart：统一 task 驱动

### 请求与状态

公开示例使用 `https://api.apimart.ai` 和 Bearer 鉴权。图片 `POST /v1/images/generations` 与视频 `POST /v1/videos/generations` 提交均返回 `{"code":200,"data":[{"status":"submitted","task_id":"…"}]}`。因此现有同步 OpenAI Images 通道若期待 `data[].url/b64_json`，仅改 base URL 无法完成异步接入。[图片](https://docs.apimart.ai/cn/api-reference/images/gemini-2.5-flash/generation.md)、[VEO](https://docs.apimart.ai/cn/api-reference/videos/veo3/generation.md)

查询为 `GET /v1/tasks/{task_id}`，可带 `language=zh` 仅改变错误消息。HTTP 成功示例为 `{code:200,data:{id,status,progress,result,…}}`；状态为 `pending / processing / completed / failed / cancelled`。`result` 在完成时提供 `images` 或 `videos`；图片示例是 `images:[{url:["…"],expires_at:…}]`，应展开全部 URL。错误响应例为 `{error:{code,message,type}}`，覆盖 400、401、402、403、429、500、502。[查询完整文档](https://docs.apimart.ai/cn/api-reference/tasks/status.md)

映射建议：提交时从 `data[]` 获取真实任务引用，轮询时从 `data` 解包；`pending/processing` 等待，`completed` 成功，`failed` 失败，`cancelled` 消费供应商终态。文档列出 `cancelled` 不代表确认可主动调用取消；当前目录没有取消端点。[提交](https://docs.apimart.ai/cn/api-reference/images/gemini-2.5-flash/generation.md)、[查询](https://docs.apimart.ai/cn/api-reference/tasks/status.md)、[目录](https://docs.apimart.ai/_llms/zh-hans/api.txt)

### 模型参数不能仅由端点统一

## 本次实施的证据边界

1. **可按文档直接写协议测试**：GRSAI 原生图片/视频提交与查询；APIMart 图片/视频提交与统一查询；小北同步图片请求/响应。以上足以实现适配器和非付费 fixture 测试，不代表已通过真实网关验收。
2. **应显式保留为不支持/未确认**：三家的远端主动取消、通用幂等键、提交超时后的重提安全性、`Retry-After`；小北视频完整终态与结果 schema；GRSAI 原生多张输出和最低价模型。没有证据时不构造取消 URL，不把本地停止等待表示为厂商已经取消。
3. **后续真实验收需要覆盖**：保存供应商任务 ID 后重启并恢复轮询；成功后将临时结果转存到现有资产链；多参考图的实际送达；失败/违规的人话原因；取消与完成竞争时的本地行为。真实请求前先确认模型价格和测试预算，尤其不能把 `fast` 或默认模型当作最低价证据。

以上第 1–3 点为实施与验收建议；本次没有执行生成、取消、恢复、结果转存或发布。


## 已实现驱动与配置入口（2026-10-15）

本节为实现回执，区别于上文只读协议研究。当前 `grsai` 驱动同时提供图片和视频工厂，直接消费共享 `startAsync/pollAsync`；没有内部轮询、重试或独立队列。服务端负责输入素材解析、上游句柄持久化、冷恢复、产物保存/发布、用量和取消意图。查询到结果不再发生成请求。

安装一个**新线协议**仍需驱动文件、共享协议声明、唯一解析注册表和数据库前向迁移；不是把任意脚本/JSON放进目录就可热加载。安装完成后，已有协议的其他网关只需配置地址、凭据和模型。Code壳协议选择器消费共享枚举；原供应商卡片的API格式选择器允许本地标准协议实例切到已安装媒体驱动，保存继续走原宿主设置通道。

GRSAI示例配置（在现有供应商设置填写；Key只在本机授权设置保存）：

```json
{
  "name": "GRSAI",
  "protocol": "grsai",
  "baseUrl": "https://grsaiapi.com",
  "models": [
    {
      "id": "nano-banana-2",
      "name": "Nano Banana 2",
      "capability": "image",
      "imageGeneration": {
        "qualities": ["1K", "2K", "4K"],
        "aspectRatios": ["1:1", "16:9", "9:16"],
        "sizes": [],
        "outputFormats": [],
        "maxOutputs": 1
      }
    },
    {
      "id": "minimax-h3",
      "name": "H3",
      "capability": "video",
      "videoGeneration": {
        "durations": [5, 10],
        "aspectRatios": ["16:9", "9:16"],
        "resolutions": ["480p", "768p", "1080p"],
        "referenceImages": 9,
        "firstLastFrame": false,
        "audio": false
      }
    }
  ]
}
```

Nano质量原生值映射到imageSize；GPT原生quality保留，像素尺寸发送aspectRatio。H3比例翻译为landscape/portrait。GRSAI当前接口未声明输出格式、原生多张数量、参考视频或音频开关，适配器明确拒绝这些参数；数量由共享引擎拆为多个Job。参考音频/seed尚未接入当前统一参数，不宣称完整覆盖厂商所有字段。视频没有真实计费验收。

GRSAI没有已确认的主动取消端点，因此不提供cancelAsync；共享引擎持久化取消并标记local_only，阻止迟到产物保存发布，不承诺停止厂商计费。没有幂等键证据，提交受理不明时仍走共享“结果待确认”，不自动重提。

真实供应商证据：按用户授权，仅调用nano-banana-2、1K单图一次（POST1、GET3，37100ms），Job成功并保存1份，ffprobe确认1024×1024，人工查看红色纸鹤。未做真实参考图、视频或远端取消。参考图送达、隔离PostgreSQL恢复（重建进程内队列后仅续查）、请求重放与本地取消由受控HTTP供应商回归提供；它们不是第二笔真实计费请求。凭据与响应产物不提交仓库。
