# 字标字体说明

本目录是品牌字标（wordmark）的字体归档：**正在使用**的那一份 + 当初挑选字标时的候选样张。

- 在用的字标字体 = `momo-trust-display.woff2`（Momo Trust Display）。注册与用途见 `apps/web/src/app/globals.css` 的 `@font-face` 与 `--font-wordmark`（侧栏品牌名、落地页标题、启动页）；运行时分发的那一份在 `apps/web/public/fonts/`，与本目录副本逐字节一致。

运行时副本旁已附 `apps/web/public/fonts/LICENSE.txt`（OFL-1.1 全文 + 版权声明，满足 OFL 第 2) 条随分发附许可的义务；2026-10-04 经 google/fonts#9129 核实上游无 Reserved Font Name，子集可沿用原名）。
- 其余 woff2 与三支 TTF 是选型阶段的候选样张，**未进入产品**，留在本目录只作设计过程留档。
