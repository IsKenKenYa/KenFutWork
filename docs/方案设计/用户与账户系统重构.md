# 用户与账户系统重构

> 角色：**实施规格**。2026-10-05 用户批准，本期本地实现与整体验收已完成，运行回执见《日志》§一百二十一、§一百二十二。产品方向与决策属主仍为《[改造计划](./改造计划.md)》与《[多端产品设计](./多端产品设计.md)》；服务 key 仅登记于《改造计划》§4.2，领域词汇仅登记于根级 `CONTEXT.md`，实施回执记《[日志](../日志.md)》。
> 决策依据：`DEC-20`；本地计费、凭证及隔离修订分别见 `DEC-5`、`DEC-7`、`FORM-9`、`FORM-10`。未来账户与远端连接见《[官方账户与远端连接基础设施](./官方账户与远端连接基础设施.md)》与 `DEC-21`。

## 1. 交付边界

本期交付单一本地实例的免账户桌面与本机 Web 体验。安装后无需注册、邮箱、密码或官方账户，用户配置自己的供应商即可运行 Design 与 Code。官方服务、本机以外的连接、SaaS、团队和企业管理不进入本期运行时；局域网配对进入下一独立阶段。

项目没有 release 和真实用户，现有数据均为开发测试数据。旧数据无需保留，不提供旧版本兼容层、假账户或假 session。迁移历史仍不可变，开发库可以重建，最终 schema 由新增前向清理迁移收敛。

Code 保持 Project → Task → Run、Execution Scope 与 Task Work。Code Task 继续持有创建时确定的主目录、附加目录授权及权限代际；Code 不创建或借用 Design 画布。Design/Flow 主区画布不变量继续生效。

## 2. 实例、调用者与存储归属

- 启动直接打开或初始化本地实例，确定稳定 `instanceId`。实例拥有项目、Task、会话、配置、插件及应用管理数据；重启、数据目录迁移和恢复不重新生成实例身份。
- 第一方调用上下文为 `LocalActor = { instanceId, accessClientId }`。实例身份回答“数据属于谁”，接入客户端身份回答“谁发起操作”；不附带账户、成员、角色、套餐、余额或访问令牌。
- 第一方持久化、队列载荷和执行契约统一使用实例归属。显式作用域谓词和跨实例拒绝仍是存储入口的责任；单实例产品不等于允许无作用域裸查询。
- 执行作用域继续从真实 Task 解析目录与授权代际。接入凭据不进入工具参数、审批、checkpoint、持久事件或模型输入；客户端身份不代替 Task 身份。
- 原 ZCode wire 协议既有 `hello.auth.userId/workspaceId` 仅在宿主边界映射到实例归属，保留原字段、可信绑定和资源校验。第一方业务不得沿用旧账户或工作区别名。

本地实例初始化不创建账户、工作区成员、订阅或管理员。旧 `/api/viewer` 由本地实例引导接口取代，返回真实实例与连接状态；接口契约以 `packages/shared` 为准，OpenAPI 按仓库单源链同步。

## 3. 本机访问与设置

桌面由可信启动链获得本机接入凭据，用户无需手动登录。“在浏览器打开”创建一次性连接入口，浏览器兑换后使用 HttpOnly 会话 cookie；脚本仅使用明确授权的 Bearer 凭据。HTTP、SSE、WS 与原宿主 RPC 消费同一本地接入验证，未获授权或伪造的凭据必须拒绝。

本期服务仅监听回环。浏览器连接不能因为请求来自回环、携带任意 Origin 或自报身份而自动获得权限；一次性入口使用后不可重放。Origin、cookie 和跨通道凭据的检查集中在接入边界。页面显示真实连接、服务启动与目录故障，不把所有失败归为“登录失效”。

本地设置只属于实例，与未来官方账户登录、退出或切换无关。已授权实例主人可管理供应商、插件及 MCP；删除平台管理员身份门，同时保留插件兼容性检查、安装校验、Task 沙箱、工具审批和治理设置。

不显示尚未接通的官方账户、余额或商业功能入口。旧注册登录、账户管理、管理员、套餐、额度和支付接口及配置退役；usage 继续记录模型调用与资源使用，所有 BYOK 路径不检查套餐或余额。

## 4. BYOK 凭据

凭据的规范属主是《改造计划》§4.8（`DEC-7`），本节定义该规范在本次重构中的消费行为。

- 供应商 Key 存放于数据根目录内的明文凭据文件，数据库保存供应商元数据及凭据引用，不再保存加密 Key。统一凭据接口封装文件存取，作为现有供应商服务的私有依赖，不新增并行配置真相。
- 沿用供应商服务、修订号/CAS 与原设置 RPC。已授权设置界面支持主动查看和复制 Key；普通模型目录、模型选择快照及公开资源列表不携带 Key。
- 服务端日志、事件和错误消息继续脱敏；调用供应商时才解析所需秘密值。供应商协议仍是封闭集合，协议扩展先改共享契约。
- Key 文件随整个数据目录迁移和备份恢复。产品界面及恢复指引须明示该目录包含明文凭据，不能把普通文件夹复制描述成安全的分享操作。

## 5. 数据目录与恢复

数据根目录统一包含本地实例元数据、Postgres 数据、应用管理的文件/附件、凭据、配置、插件与会话恢复数据。路径由宿主配置管理；各服务消费解析后的目录，避免凭据、插件、blob 和 checkpoint 分散在多个独立根。

整体迁移按以下顺序执行：等待在途工作结束 → 停止服务及数据库 → 复制目录 → 校验副本 → 切换启动位置 → 重启并验证实例。复制、校验或切换失败时继续使用原目录，不能提前破坏原目录；迁移不移动用户授权的外部代码目录。

本期提供目录入口和停机文件夹备份/恢复指引，不新增内置打包器、单会话导入或远端同步。备份必须在服务和数据库停机后复制；恢复保留实例身份、供应商配置与会话上下文。外部项目路径缺失时提示重新关联，不把它伪装成可执行目录，也不自动重放之前的任务。

## 6. 实施与验收

按文档决策 → 实例与引导 → 本机访问 → 分域上下文迁移 → 凭据与设置 → 旧身份/计费退役 → 数据目录 → 前向 schema 清理推进。过程允许逐个垂直切片迁移消费者；最终交付不得留下第一方身份兼容 shim 或未接线的替代实现。

| 场景 | 验收结果 |
| --- | --- |
| 无账户冷启动、重启 | 同一实例直接可用，不创建账户/成员/订阅 |
| 桌面与本机浏览器 | 访问同一项目、Task 与设置；一次性入口重放、伪造凭据均拒绝 |
| HTTP、SSE、WS、RPC | 接入规则一致，失败给真实可读原因 |
| BYOK 聊天及图/视频生成 | 无套餐或余额门；usage 保留；Key 仅在授权设置读取 |
| 供应商设置并发更新 | revision/CAS 保留，冲突不能静默覆盖 |
| 插件/MCP 与 Code | 实例主人可管理；越界、只读派生、撤权、旧代际拒绝与审批继续有效 |
| 子代理、Task Work 与恢复 | 幂等执行、迟到结果、分支恢复、附件/checkpoint、资源关闭不因身份替换退化 |
| 目录迁移失败、备份恢复 | 原目录仍可启动；恢复后上下文可继续；缺失外部路径提示关联且不自动重放 |
| 空库重放与第二次运行 | 历史 SHA 不变；最终 catalog 无旧账户和商业对象；第二次为 no-op |
