# 官方账户与远端连接基础设施

> 角色：**基础设施规格（仅文档）**。2026-10-05 用户批准边界，本期不实现官方登录、远端计算、SaaS、团队或企业版；本稿不表示任何远端服务已经可用。决策属主为《[改造计划](./改造计划.md)》`DEC-21`，本地交付见《[用户与账户系统重构](./用户与账户系统重构.md)》。术语唯一属主为根级 `CONTEXT.md`。

## 1. 三种身份边界

| 概念 | 归属与授权 | 对本地实例的影响 |
| --- | --- | --- |
| 本机接入凭据 | 实例授权一个客户端接入 | 不创建账户，不改变数据归属 |
| 供应商凭据 | 用户在供应商处获得的模型调用资格 | 保存在本地配置，独立于官方账户 |
| 官方账户 | 由官方身份签发方识别并获得对应服务权益 | 只授权官方服务，不成为本地资源所有者 |

官方身份用“签发方 + 稳定主体标识”识别，邮箱、昵称或本机实例标识不能替代它。未来登录使用系统浏览器，桌面宿主接收并验证返回结果；账户凭据的持有与服务请求封装在连接边界，不写入 Task 的工具参数、审批、日志或模型输入。具体登录协议、服务产品和计算承载方式在服务实现时确定。

登录、退出和切换账户不改变本地项目、会话、供应商、Key、插件与治理设置。官方服务的授权错误只影响该服务，不阻断免账户本地启动或 BYOK。客户端不通过伪造本地用户、全局管理员或单一套餐字段把三种身份合并。

## 2. 最小接口责任

本期只确定责任边界，不提前生成未使用的 wire schema、数据库表、ctx key 或空 Provider。

- **身份边界**：开始/完成系统浏览器登录、读取当前官方主体、退出；返回主体来源与状态，不返回可被业务持久化的原始令牌。
- **服务权益边界**：按具体服务查询当前主体的授权与必要使用信息，明确授权所属签发方和服务；本地权限不经此接口判定。
- **远端连接边界**：建立/关闭连接、读取连接状态与当前授权；每个连接保留来源实例，自部署身份独立于官方身份。
- **资源边界**：列举和操作远端资源时携带来源实例与远端资源标识，按当前连接授权过滤；本地资源始终保留。
- **执行边界**：提交任务时确定执行目标及提交主体，读取/取消使用原目标；Task 不跟随界面账户切换而迁移。

这些责任按现有插件三元组落地：服务定义、Provider 与真实消费者一起交付。服务 key 的新增仍只登记《改造计划》§4.2；不能为了“未来扩展”在本期内核注册无实现服务。

## 3. 资源与任务生命周期

本地列表始终包含本地资源。已连接远端的资源按来源及当前授权追加；来自不同实例的相同资源 ID 不能混为一项。账户退出或授权变化可以让远端资源暂时不可见，不能删除本地项目，也不能把暂时无权读取解释为资源已删除。

远端任务提交时固定执行目标和提交身份。退出官方账户、关闭桌面窗口或切换到另一账户不取消远端任务，也不自动把任务改为新账户执行。重新获得原连接授权后可以查询原任务；取消只能作为指向原执行目标的显式操作。具体云端承载、任务调度、额度预留和结算规则须由未来对应服务规格定义，本稿不确定商业细则。

客户端连接多个来源时，展示来源与授权状态，动作始终发向资源原来源。授权失效时给出对应服务的可读原因；禁止静默改用本地 BYOK 或其它账户重新执行同一远端请求。

## 4. 自部署、插件权益与局域网

**自部署**：Docker 或用户服务器上的实例独立运行并持有自己的身份与授权配置，官方账户不是启动或 BYOK 前提。自部署认证的产品档位另行决策，不用当前本地免账户规则给公共网络上的请求放行；团队和企业管理本期不实现。

**插件权益**：已经有效授权的本地插件可继续使用；更新、在线下载或其它官方服务可要求对应账户及服务授权。授权记录与具体插件/服务绑定，不能通过退出账号删除安装文件或禁用全部本地插件。商品、价格、有效期、离线期限、撤销与退款细则均留待该服务立项时确定。

**下一阶段局域网**：默认关闭；每台设备独立配对，桌面主人确认后授予接入权，可独立撤销。配对设备等同实例主人，不能被描述为只读查看器；界面须明确其能力。传输、证书与发现方案在该阶段选择，当前服务继续只监听回环，不提前展示空入口。

## 5. 后续服务的验收场景

| 场景 | 必须成立的边界 |
| --- | --- |
| 无官方账户或官方服务不可用 | 本地项目、配置和 BYOK 继续可用 |
| 官方登录、退出、切换账户 | 本地数据与 Key 不变；远端列表按新授权变化 |
| 两个签发方主体标识相同 | 保持为不同官方身份 |
| 两个远端资源 ID 相同 | 按来源实例区分，操作不会发错来源 |
| 远端任务运行时退出/关闭客户端 | 任务继续由原目标执行，不自动取消 |
| 切账户后尝试操作原远端任务 | 先验证原来源授权，不自动改用新账户 |
| 自部署实例未连接官方服务 | 独立启动及 BYOK 正常工作 |
| 退出账户但本地插件授权有效 | 本地使用继续；需要账户的更新给可读提示 |
| 单台配对设备被撤销 | 只影响其接入权，不删除实例数据或取消别的任务 |

未来服务实施须补齐自己的真实故障、幂等、恢复、迁移与测试证据；此处只冻结跨服务边界，不替代服务 API 和商业规则设计。
