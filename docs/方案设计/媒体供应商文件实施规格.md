# 可安装媒体供应商与 AI 配置助手

用户于 2026-10-22 确认实施。方向与服务依赖见《改造计划》，本文件记录供应商文件接口、执行和交付要求。实现进度及验证证据见《日志》与《媒体生成供应商适配核验》。

## 用户操作

唯一配置入口为设置中的模型设置，沿用现有 ZCode 组件与设计规范。用户通过 `.ts` 文件导入、粘贴代码或现有 Agent 生成文件。安装前展示模型、参数、连接字段、访问地址和文件摘要；用户确认添加后保存。格式检查、安装与真实接口验证分别显示结果，安装不自动请求计费生成。

配置 Task 归属本地实例，使用应用数据根目录中的独立子目录，保留真实 Task ID、历史和授权代际。宿主创建目录和权限，工具及上下文读取共同遵守配置用途；文档登录由用户在现有浏览器中操作。

## 文件接口 v1

文件自包含，运行期不导入模块。`manifest` 是可静态读取的普通对象，导出 `apiVersion: 1`、供应商标识和版本、模型、连接字段及允许访问的完整网站地址。可以导出函数声明或函数表达式形式的方法。

- `prepareInputs`：可选，在付费提交前准备素材。
- `submit`：单次请求，返回 `succeeded` 的 `outputs[]`，或 `pending` 的 JSON 句柄；失败为统一错误。
- `query`：异步模型必须提供，每次仅查询一次，返回等待、产物或失败。
- `cancel`：可选，单次远端取消；未提供时沿用本地停止。

共享定义以 `packages/shared/src/media-driver-contracts.ts` 为准。v1 供应商标识为 1—128 个小写 ASCII 字母、数字或连字符，首字符为字母，适配文件目录及数据库索引。模型声明复用现有图片、视频能力；供应商特有参数支持文字、数字、开关、选项及文字列表。秘密连接字段不提供源码默认值。文件大小默认 1 MiB，经现有治理设置和环境变量调整，前后端采用相同预算。

预览使用 Babel TypeScript 语法树和 esbuild，仅解释声明数据并编译，禁止调用待导入代码。检查结果标记为 `format_only`。`POST /api/media-drivers/preview` 要求本机授权，返回文件摘要、模型及方法，不回传编译代码。

## 保存与执行

源码、编译文件和配置目录使用应用数据根目录。版本不可变；数据库保存安装态、版本索引、模型绑定和访问授权。自部署 API 与 Worker 共用相应数据卷。

同一供应商保留标准聊天连接，媒体模型分别选择驱动。接纳 Job 时冻结驱动版本、文件摘要、模型参数及配置引用；后续提交、查询、恢复和取消使用相同版本。

驱动在专用身份的独立受限进程中执行。进程断网，通过宿主访问已确认的网站、素材和凭据操作。宿主检查每次请求和重定向；Key 只用于对应授权地址，下载产物不带供应商凭据。沙箱不可用时拒绝执行。桌面与自部署 Worker 使用相同模块，发布包含 helper 和必要运行依赖。

共享 Job 继续负责查询时间、重试、Retry-After、租约、启动恢复、下载保存、画布发布和 usage。一个 Job 对应一次上游生成请求，多个产物通过 `outputs[]` 保存；未知原生数量能力按单图请求。结果待确认时，仅有上游幂等保证才允许自动重新提交。取消、文档删除及权限变化继续由现有发布检查保护。

## 安装与更新的持久操作

安装、更新及卸载使用宿主签发的内部资源 ID、操作代际和预期修订形成稳定业务键，参数指纹单独保存。同键同参数返回原回执，同键不同参数返回 409；同一事务内认领操作、核对修订及切换当前版本。文件在数据库引用前完成持久保存，失败保留明确恢复记录。

更新先显示模型及能力变化，保留用户修改的名称、启用状态和默认参数。新 Job 使用确认后的版本，旧 Job 保留原版本。

有在途生成或取消处理时，只允许停用新任务；处理结束后卸载。用于拒绝迟到请求的删除标识仅保留内部 ID、代际和时间，随实例物理删除级联清除；不保存模型名称、地址、文件内容或内容摘要。旧代际安装、更新与发布请求不能恢复已移除配置。

## 交付顺序

每批开始列明文件和修改段、用途、依赖及完整验证命令。一条行为完成并通过范围测试和类型检查后立即提交，提交包含完整消费方，同步日志与核验记录。

| 批次 | 行为 | 依赖 |
| --- | --- | --- |
| 1 | 共享定义、治理设置、解析编译、预览 HTTP 与 OpenAPI | 当前基线 |
| 2 | 版本保存、安装更新、停用卸载、连接字段与凭据 | 1 |
| 3 | 独立执行、宿主网络及素材方法、桌面和 Worker 发布 | 2 |
| 4 | 媒体模型绑定、Job 版本冻结、恢复、取消和产物 | 2、3 |
| 5 | 现有模型设置及生成面板的导入、粘贴、预览和更新 | 4 |
| 6 | 实例配置 Task、文档浏览、AI 生成与返回预览 | 5 |

测试从文件预览安装接口、实际脚本进程及受控 HTTP、现有设置画布、真实 PostgreSQL 的 Job/Worker 四个公开入口进行。覆盖并发重放、同键冲突、回执丢失、删除后迟到请求、旧版本续查、部分成功及取消竞态。共享定义改动运行完整 workspace、串行包测试、类型、lint 和 Code UI 构建。数据库回归显式启用并记录结果；平台执行与真实计费调用分别记录。
