# ADR-20260912-DEC-9：register-all / http-models / env 三选一退役随 BYOK 切换（D3）执行

> 状态：已采纳（2026-09-12，维护者）
> 原条目：《改造计划》§9 完成度量第 3 条

## 背景

§9 完成度量要求「`http/models.ts` 硬编码目录、`deep-agent.ts` env 三选一、`register-all.ts` 副作用注册全部退役」。P4–P5 已新增实例驱动的等价路径（`providers/<protocol>/` 适配器 + `modelProviders`/`modelCatalog` 缝 + `/api/models` 目录合并），但存量部署尚无用户供应商实例；立即删除 env 路径会使现有云端部署的聊天/图/视频生成失去模型来源且不可回退，直接违背「每个 PR 行为不变」纪律（§7）。退役时点必须正式拍板，避免「延迟」停留在快照备注而缺乏决策效力。

## 决策

三条 env 驱动的存量路径作为**迁移期存量并行**保留，其全量退役**绑定《多端产品设计》D3（自管 Postgres 落地、桌面端到端离线可用）的 BYOK 切换 PR** 一并执行：

1. `generation/providers/register-all.ts` 按 env 副作用注册 → 由 `providers/resolve.ts` 实例驱动注册表取代；
2. `http/models.ts` 内置硬编码目录 → 由 `modelCatalog` 推导目录取代（内置目录转为种子数据）；
3. `deep-agent.ts` `createStreamingChatModel` env 三选一（含 `streamUsage: false`）→ 由实例适配器（`streamUsage: true`，用量采集依赖）全面取代。

切换前置条件：存量部署完成用户实例迁移（env Key → `provider_instances` 加密落库），切换 PR 同时移除三条路径及其 env 变量、同步 §9 度量核销。

## 备选与取舍

- **P5 立即退役**：存量部署生成/对话立即不可用且不可回退，否决。
- **无限期保留双路径**：双采集/双目录长期并存会持续扩大维护面，且 `streamUsage: false` 与用量统计（DEC-6）冲突，D3 是自然的强制切换点，否决。

## 后果

- 正面：行为不变纪律与完成度量冲突正式消解；退役有唯一明确触发点（D3 切换 PR），不依赖自觉。
- 负面：§9 第 3 条度量在 D3 前保持「部分达成」（缝已建、存量并行）；双路径短期并存。
- 同步：`future/02` §9 复核已按本结论标注；`改造计划` §9 已就地注明退役时点。
- 重新评估条件：D3 开工时核销本决策；若存量迁移进度滞后，退役可再延一档但需新 ADR。
